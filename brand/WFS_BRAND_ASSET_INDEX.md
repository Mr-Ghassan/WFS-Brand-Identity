## Conventions

- **Naming:** `WFS_[Asset]_[Layout]_[Colourway]_[size]px.[ext]`
- **Colourways:** `Primary` full colour for light grounds · `Inverse` full colour for dark grounds · `Dark` / `White` / `Black` / `Teal` one colour · `Monochrome` greyscale tonal (light grounds) · `Monochrome_Light` greyscale tonal (dark grounds) · `Premium` dimensional display version (dark grounds) · `Premium_Light` (light grounds)
- **PNG** logo files are transparent; sizes are the *width* for lockups/wordmarks and the *height* for icons.
- **SVG** masters: outlined paths only, no embedded rasters, no live text, no editor metadata. **PDF**: single-page vector.
- Core colours: `#022329` WFS Dark · `#0E3D42` WFS Deep Teal · `#14B8A6` WFS Primary Teal · `#7FE3D6` WFS Light Mint · `#F3F5F2` WFS Soft Off-White

## Not included (and why)

- `WFS_Wordmark_Dark` / `WFS_Wordmark_Monochrome`: the wordmark is one colour by construction — the primary wordmark **is** WFS Dark, and the monochrome wordmark **is** `WFS_Wordmark_Black`. Exporting aliases would create duplicate files.
- `WFS_Logo_Full_Bilingual`: requires the licensed **Myriad Arabic** font to outline the Arabic descriptor. It was not available in the build environment; no substitute font was used. Add the font to `$WFS_FONT_DIR` and run `source/build_all.sh` to generate it.
- Native `.ai`: see above.
